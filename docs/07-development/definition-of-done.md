# Definition of Done

Una feature puede pasar a `DONE` cuando:

- [ ] Criterios de aceptación cumplidos.
- [ ] Código revisado.
- [ ] Unit/integration/E2E según aplique.
- [ ] CI aprobado.
- [ ] Sin secretos ni hallazgos críticos conocidos.
- [ ] Cambios de API reflejados en OpenAPI.
- [ ] Cambios de BD incluyen migración.
- [ ] Documentación actualizada.
- [ ] Observabilidad actualizada si aplica.
- [ ] QA/UAT completado según el flujo.
