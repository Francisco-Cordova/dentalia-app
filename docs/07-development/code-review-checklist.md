# Code Review Checklist

- [ ] El cambio corresponde a la feature.
- [ ] La lógica está en la capa/módulo correcto.
- [ ] No introduce duplicación innecesaria.
- [ ] Maneja errores y casos límite.
- [ ] Valida autorización server-side.
- [ ] No expone secretos/datos sensibles.
- [ ] Cambios de BD/API están documentados.
- [ ] Pruebas son suficientes para el riesgo.
- [ ] No hay cambios no relacionados.
